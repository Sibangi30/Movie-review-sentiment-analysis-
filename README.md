# 🎬 Movie Review Sentiment Analysis System

### Problem Statement : 
The traditional movie recommendation systems only use movie viewing history and rating data to create a recommendation but this sometimes isnt enought to give an accurate picture of what the viewers’ opinions of the movies have been. Analyzing the text of reviews with Sentiment Analysis is a way to get more insightful data about user preferences and experiences, thus helping to classify the sentiment of the review and create meaningful feedback that helps improve the recommendations and ultimately improves the user experience.

### Key Features
**Text Preprocessing Pipeline:**
The text was cleaned and feature extraction was done through tokenization, stop-word removal, lemmatization, and removing outliers and html tags,expanding abbreviations and  to improve model performance.

**Multi-Model Sentiment Classification:**
Various models were implemented as follows:

* Naive Bayes
* Logistic Regression
* Linear Support Vector Machine (Linear SVM)
* DistillBERT

**Sentiment Prediction Engine:**
Analyzes user-provided movie reviews and instantly predicts whether the sentiment is positive or negative.

**Performance Evaluation Dashboard:**
Measures model effectiveness using metrics such as Accuracy, Precision, Recall, F1-Score, and Confusion Matrix for comprehensive comparison.
